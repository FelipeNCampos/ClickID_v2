Como funciona?

Este recurso permite adicionar dados extras aos cartões já cadastrados usando um arquivo Excel.

  • O Excel deve conter uma coluna CPF para identificar o cartão
  • As demais colunas serão salvas como dados adicionais
  • Exemplos: CREA, RG, CNH, Carteira de Trabalho, Endereço, etc
  • Os dados ficam disponíveis para uso em formulários futuros
Formatos aceitos: .xlsx ou .xls
